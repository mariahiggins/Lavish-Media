# Lavish Media

Website for Lavish Media, a social media agency in Houston, TX, by Maria Higgins.

- `index.html`: Home
- `about.html`, `services.html`, `portfolio.html`, `contact.html`: the other pages
- `assets/`: photos and video
- `lm.js`: the small script that draws each page

Hosted on Netlify. Every change pushed here goes live automatically.
